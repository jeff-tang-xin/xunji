玄机万象 XuanJi静态原型 v0.1

全流程编排与自定义 Agent 平台 · 页面静态预览（数据为 mock，经本地 HTTP 预览：http://localhost:8321/）

① 工作区

项目名（路径 = 系统配置根目录/项目名，动态生成）+ 工作流绑定 + Agent 决策授权；阶段化 SSE 对话交互。

② 画布编辑器

节点面板 + LogicFlow 画布 + 属性抽屉（决策门/重试/超时）+ 发布校验。SDLC 七阶段示例流程。

③ 运行监控

run 列表 + 节点状态实时推进（模拟 SSE）+ 节点输入输出查看 + SUSPENDED 审批入口。

④ 决策工作区

交互式决策：产物审阅 + 实时批注 + 在线修改；决策只是下一步的前提（修改后产物流向下游节点）。

⑤ 发布中心

五类资产统一生命周期（草稿→发布→弃用→下线）、版本历史、bundle 导入导出。

⑥ Agent 管理台

agent_config 全配置化：模型协议双轨 / 提示词 / 工具绑定 / 权限策略 / 发布。

⑦ 应用管理

App 绑定已发布资产、AppKey 创建（明文一次性展示）、限流白名单、嵌入代码生成。

⑧ 报表中心 工作报表场景

workflow 周期生成的数据报表：报表列表 → 看板详情（KPI / 趋势图 / Agent 分析摘要 / 明细）。

⑨ 权限管理 RBAC

用户→角色→菜单 RBAC、组织树、数据权限四档（all / under_org / org / only_create）；用户仅由 admin 创建，密码明文一次性展示。
原型说明：本组页面为静态原型（React 18 + AntD 5 + LogicFlow 2 UMD 本地包，mock 数据内联），用于在 P1 开发前确认布局与交互，不连接任何后端。 每页顶部有原型说明条，标注对应详细设计文档章节（docs/detail/06-frontend-and-delivery.md §1）。 交互深度：布局静态展示 + 抽屉/弹窗可点 + 运行监控定时器模拟 SSE。
